# Sugar Cube

Page de présentation de Sugar Cube, pâtisserie sur commande à Bordj Bou Arreridj 🇩🇿
صفحة تعريفية بـ Sugar Cube، حلويات حسب الطلب في برج بوعريريج.

## Site

https://sugar-cube.netlify.app/

## Langues

Arabe (par défaut), français et anglais, avec trois boutons en haut de la page.
Le choix du visiteur est mémorisé. Les textes sont dans `index.html`
(chaque texte existe en trois versions : `data-l="ar"`, `data-l="fr"` et `data-l="en"`).

## Fichiers à garder ensemble dans le dossier

- `index.html`
- `style.css`
- `script.js`
- `Sugar-cube-logo-480.webp` et `Sugar-cube-logo-900.webp` (logo léger)
- `Sugar-cube-icon.png` (icône de l'onglet)
- `Sugar-cube-share.png` (aperçu du lien sur WhatsApp, Facebook...)
- `Sugar-cube-logo.png` (logo original, à conserver comme archive)
